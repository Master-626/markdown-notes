[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Notes Tool](https://img.shields.io/badge/notes-tool-green.svg)]()

A simple Markdown note-taking CLI with tags and search.

## ✨ Features

- **Quick Notes** - Create Markdown notes from terminal
- **Tags** - Organize notes with tags
- **Search** - Full-text search
- **List** - View all notes
- **Rich UI** - Beautiful colored output

## 📦 Installation

```bash
git clone https://github.com/Master-626/markdown-notes.git
cd markdown-notes
pip install .
```

## 🚀 Quick Start

```bash
# Add a note
mnotes add "Meeting Notes"

# List notes
mnotes list

# Search
mnotes search meeting
```
